# BMI Calculator

## Project Overview
The BMI Calculator is a Python-based application developed as part of the Oasis Infobyte Python Programming Internship.

It calculates the Body Mass Index (BMI) of a user based on their weight and height and displays the corresponding BMI category.

## Technologies Used
- Python 3.14.3
- VS Code

## Features
- Accepts weight in kilograms.
- Accepts height in metres.
- Calculates BMI using the standard formula.
- Classifies BMI into four categories:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Displays BMI rounded to two decimal places.
- Handles invalid and negative inputs with error messages.

## BMI Formula

BMI = Weight (kg) / Height (m)²

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this project.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   `python main.py`

6. Enter your weight and height when prompted.
7. View your BMI result and category.
