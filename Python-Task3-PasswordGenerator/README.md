# Password Generator

## Project Overview
The Password Generator is a Python-based application developed as part of the Oasis Infobyte Python Programming Internship.

It generates random and secure passwords based on the length entered by the user.

## Features
- Generates random passwords.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Allows users to choose password length.

## Technologies Used
- Python 3.14.3
- Random module
- String module

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python main.py
```

4. Enter the desired password length.
5. The generated password will be displayed.
