# Basic Weather App

## Project Overview
The Basic Weather App is a Python-based application that allows users to check the current weather information of any city. It fetches live weather data using the Open-Meteo API.

## Features
- Enter any city name to check its weather.
- Displays current temperature.
- Shows feels-like temperature.
- Displays weather conditions.
- Shows humidity and wind speed.
- Displays precipitation.
- Handles invalid city names.
- Handles network and API errors.

## Technologies Used
- Python 3
- Open-Meteo API
- JSON
- urllib module

## How to Run
1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

`python main.py`

5. Enter the city name when prompted.

## Example
Input: Pune

Output: Weather report containing temperature, humidity, wind speed, weather conditions and precipitation.

## API Used
Open-Meteo: https://open-meteo.com/
